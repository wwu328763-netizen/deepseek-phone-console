安装到手机

把“远程控制台”装成独立 App，从手机桌面一键打开。

打开本页 → 点分享按钮 → “添加到主屏幕” → 确认。
浏览器菜单 → “安装应用”或“添加到主屏幕”。若没有安装选项，请用外网 HTTPS 隧道地址访问后再安装（详见 README）。
